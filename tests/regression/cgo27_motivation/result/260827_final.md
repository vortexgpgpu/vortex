# CGO27 motivation: final all-mode results (updated 2026-08-28)

This document combines the full 2026-08-26 sweep, the corrected m3/m5
measurements from 2026-08-27, and the s2048 extension measured on 2026-08-28:

- For the original eight shapes, m1, m2, m6, m7, m8, and the a1/a6/a9
  pipeline results come from
  `260826_data/exp1_full_bypass1000_heavyfirst_20260826.csv`.
- m3 and m5 come from
  `260827_data/exp1_m3_m5_final_20260827.csv` after the TBUF rollover and
  LMEM K-chunk fixes.
- For m14/m15 with a2/a3/a4/a5, the tables use the best result among requested
  `MOTI_PIPE_CONSUMER_WARPS={1,2,3,4,6,8,10,12,14,16}` from
  `260827_data/consumer_width_sweep_20260827.csv` and
  `260827_data/consumer_width_sweep_6_10_12_14_16_20260827.csv`.
- s2048 all-mode results come from
  `260828_data/exp1_s2048_all_modes_20260828.csv`; its a2/a3/a4/a5 pipeline
  entries use the best width from
  `260828_data/consumer_width_sweep_s2048_20260828.csv`.
- All 567 base all-mode entries and all 720 main consumer-width entries completed
  with `status=ok` and `errors=0`.

The application mapping follows the CSV files: a1=Baseline, a2=ReLU,
a3=GELU, a4=Residual, a5=Scale, a6=Softmax, and a9=Column mean broadcast.

An asterisk in the winner table indicates that at least one other mode is
within 1% of the minimum cycle count.

- m14 winner counts over 36 shape x epilogue cells: c1=2, c2=8, c3=1, c4=12, c6=6, c8=4, c10=1, c14=1, c16=1.
- m15 winner counts over 36 shape x epilogue cells: c1=3, c2=9, c3=8, c4=7, c6=6, c8=2, c14=1.
- No single width is universally best. c16 is effective c15; all 72 c16 rows exactly reproduce c15.
- s2048 moves the optimum toward wider consumers for GELU/Scale: m14 uses c15 for a3 and c14 for a5, while a2/a4 prefer c6.
- Against the non-pipelined counterpart with the same placement, tuned m14
  beats m7 in 17/36 cells and tuned m15 beats m8 in 18/36 cells.
- Relative to c15, the best m14 width improves by a median 6.2% (range 0.0%
  to 49.3%); the best m15 width improves by a median 14.4% (0.3% to 70.2%).
- Across the main grid, pipeline global wins occur at s1024 a5 and s2048 a1/a4/a5/a9.

## Cluster-placement boundary search (2026-08-28)

The search varied K, M, N, and all ten consumer widths. It found real cases
where tuned cluster_pipe beats tuned socket_pipe, but no tested case where m8
or m15 is the global all-mode winner on the current 4-core, four-socket
(`SOCKET_SIZE=1`) machine.

The closest global case is Residual at 64 x 2048 x 64: cluster_pipe wins
against both socket modes (15.2% over tuned m14 and 4.3% over m7), but misses
TCU by 5,407 cycles, or 1.11%. Under the document's <=1% near-tie rule this is
just outside a tie. The N=1024--4096 ladder and M=64--256 ladder did not expose
a global cluster winner.

The measured conclusion is therefore that shape tuning alone is insufficient to
make cluster placement globally optimal on this target. A robust cluster winner
needs an architectural change that removes its structural disadvantage--for
example more than one L2 data path for the cluster engine, or a topology with
fewer socket engines (`SOCKET_SIZE>1`). Reporting m15 as a winner from only the
m14/m15 comparison would be incorrect because TCU/m7/wgSB still dominate it.
